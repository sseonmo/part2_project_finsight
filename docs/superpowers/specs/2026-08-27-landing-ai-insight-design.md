# 랜딩 — AI 인사이트를 앞세운 개편

2026-08-27 · 대상 `src/app/(marketing)/`

## 왜 고치나

랜딩이 밋밋하고, 이 제품의 유일한 차별점인 **지적 문장(AI 인사이트)** 이 첫 화면에 없다.

지금 히어로 오른쪽 칸은 `DashboardGlancePreview`(총 지출 + 카테고리 막대)라 처음 3초에는 "CSV·분류·집계"만 보인다. 인사이트는 한참 스크롤해야 나오는 "이런 문장을 받게 됩니다" 섹션(텍스트 카드 3장)과 3단계 중 3번째에만 있다.

**목표.** 스크롤 전에 "이 서비스는 내 지출에서 바꿀 지점을 짚어 준다"를 알아채게 한다. 시각적으로 눈을 붙잡되, 제품이 실제로 하는 일과 어긋나지 않는다.

## 지키는 선

`CLAUDE.md` 의 CRITICAL 규칙에서 온다.

- 모든 수치는 SQL 집계 결과다. **LLM은 숫자를 계산하지 않는다**
- **무엇을 지적할지도 LLM이 고르지 않는다.** `src/lib/signals/` 의 결정론적 코드가 고르고, 우선순위는 원화 영향도 점수가 정한다

→ 랜딩에서 **"AI가 분석해 드립니다" 류 문구를 쓰지 않는다.** 강조할 수 있는 것은 "AI가 문장으로 옮겨 준 지적"이지 "AI의 분석력"이 아니다.

**이 제약을 차별화로 뒤집는 것이 이 개편의 축이다.** 남들은 "AI가 분석했습니다"라고만 하고 근거를 못 보여준다. 이 제품은 분업(규칙이 고르고 → SQL이 계산하고 → AI가 문장으로 옮김)을 화면에서 직접 보여줄 수 있다. 히어로의 원자료 토글과 근거 뒤집기가 그 장치다.

기존 제약도 그대로 지킨다.

| 제약 | 출처 |
|---|---|
| 정본 3단계 문구 — 랜딩·빈 대시보드·시작하기 카드가 같은 문구 | `docs/UX_GUIDELINE.md` "계단은 하나다" |
| 미리보기는 스크린샷이 아니라 실제 컴포넌트를 예시 데이터로 렌더 | `docs/UX_GUIDELINE.md` V0 |
| 예시임을 명시 | 현행 랜딩 |

기존 5개에서 2개가 늘고, 1개가 흡수되어 사라진다.

**"이런 문장을 받게 됩니다" 섹션은 삭제한다.** ①이 그 내용을 히어로로 끌어올렸다. 그 섹션이 지던 두 가지 의무는 넘겨받는다 — "예시" 배지는 ①과 ⑤의 미리보기에, "AI는 숫자를 계산하지 않는다" 문구는 ①의 신뢰줄(`trustline`)에.

②~⑤에는 섹션 라벨(`● 무엇을 올리나` / `● 무엇을 잡나` / `● 무엇을 하나` / `● 무엇을 보나`)을 제목 위에 둔다. 넷이 이어지며 서사의 단계를 드러낸다.

### ① 히어로

2열. 왼쪽은 카피와 CTA, 오른쪽은 인사이트 카드 스택.

- **제목**: "지난달과 뭐가 달라졌는지, 문장으로 짚어 드립니다"
- **설명**: "카드 명세서 CSV 한 장이면 됩니다. 지출 급증·튀는 결제·구독료 인상을 찾아 금액과 함께 알려 드립니다."
- **신뢰줄**: "**금액은 계산된 값입니다.** 무엇을 지적할지는 정해진 규칙이 고르고, AI는 그 숫자를 문장으로 옮기기만 합니다. 오른쪽 토글로 직접 확인해 보세요."
- **카드 3장**: 카테고리 급증(카페/간식 +62,000원) · 구독료 인상(연 36,000원) · 이상 결제(180,000원). 겹쳐 쌓이고 4.6초마다 순회
- 스택 위에 "예시" 배지와 `규칙이 고른 것` / `AI가 옮긴 문장` 세그먼트 컨트롤

### ② CSV → 지적

왼쪽에 날것 CSV 9줄, 화살표, 오른쪽에 지적 3건 + "외 2건 · 원화 영향도가 큰 순서로".

### ③ 지적 5종

`SIGNAL_TYPES` 5종을 그리드로 편다. 구독료 인상이 전폭 리드 타일(영향도 금액 포함), 나머지 4종이 3열 그리드, 6번째 칸에 점선 타일 — "걸린 것이 없으면 없다고 적습니다. 없는 지적을 지어내지 않습니다."

조건 문구는 `SIGNAL_THRESHOLDS` 의 실제 값에서 온다.

### ④ 3단계

문구는 정본 그대로. **3번째 미리보기만 인사이트 카드 → 근거 패널(거래 행 + 합계)로 바꾼다.** ①과 겹치던 것이 이걸로 풀리고, "지적받은 문장을 열어 근거를 확인한다"는 자기 문구와도 정확히 맞는다.

### ⑤ 대시보드

기존 히어로의 `DashboardGlancePreview` 를 크게 키운 형태. 도넛 + 카테고리 막대 6행, 오른쪽 아래에 인사이트 카드가 떠 있고 그 위에 노란 플래그("바꿀 지점 5건 중 1").

## 인터랙션 4종

전부 `prefers-reduced-motion: reduce` 에서 트랜지션이 꺼진다.

### I1. 원자료 ↔ AI 문장 토글 (①)

같은 지적을 두 상태로 전환한다.

| 상태 | 내용 |
|---|---|
| `규칙이 고른 것` | `signal` / `target` / `prev` / `current` / `impact` / `threshold` 를 모노스페이스 키-값으로. 임계값 통과 표시(`+58% ≥ 50% ✓`)는 `--success-accent`. 아래에 출처 파일 경로 |
| `AI가 옮긴 문장` | 지금의 인사이트 문장 |

토글 아래 설명줄도 함께 바뀐다 — 원자료 쪽은 "AI는 아직 아무것도 하지 않았습니다".

**표시하는 값은 `src/lib/signals/` 의 실제 필드명·임계값과 일치해야 한다.** 예시 데이터는 상수로 두되, 임계값 숫자는 `SIGNAL_THRESHOLDS` 에서 읽어 문자열을 만든다(`SIGNAL_CONDITION_COPY` 가 이미 같은 일을 한다).

### I2. 근거 뒤집기 (①)

`근거 보기 →` 를 누르면 카드가 3D로 뒤집혀(`rotateY(180deg)`) 그 금액을 만든 거래 행과 합계가 나온다. 뒷면에 `← 돌아가기`.

### I3. 숫자 하이라이트 + 근거 툴팁 (①⑤)

인사이트 문장 안의 금액·비율에 형광 배경(`--landing-mark`)을 깔고, hover·focus 시 근거 툴팁이 뜬다(예: "거래 12건을 더한 값 · 106,000원 → 168,000원"). `tabindex="0"` 으로 키보드 접근 가능.

### I4. CSV ↔ 지적 연결 (②)

CSV 줄이나 지적 행에 hover·focus·click 하면 대응하는 것만 밝아지고 나머지는 흐려진다. 양방향. 컨테이너의 `data-focus` 속성으로 CSS가 처리한다.

**자동 순환은 사용자가 손대는 순간 영구히 멈춘다** — 스택 hover, 점 클릭, 토글, 카드 뒤집기 중 무엇이든. 읽는 중에 넘어가는 것을 막는다.

## 시각 처리

### 배경

**손대지 않는다.** 히어로와 ⑤ 대시보드 뒤의 은은한 글로우 두 곳뿐이다. 격자 패턴·컬러 메시 오브·섹션 교대 밴드는 검토했으나 전부 뺐다.

### 카드 강조

- **상단 액센트 라인 3px** — 인사이트 카드(카테고리 색), ②의 지적 행, ③의 신호 타일, 연간 요금제(`--ink`)
- **3단계 카드는 액센트를 진행률로 쓴다** — 1단계 33% / 2단계 66% / 3단계 100% 너비. 장식이 아니라 정보다
- **hover 들어올림** — `translateY(-1px)` + `--landing-lift-hover`

전부 기존 `--cat-*` 10색을 그대로 쓴다. 새 색을 만들지 않는다.

## `docs/DESIGN.md` 개정

"랜딩만 쓰는 다섯 값" 절 옆에 **"랜딩만 허용하는 표현"** 절을 신설한다. 코드만 바꾸고 문서를 안 고치면 다음 사람이 원칙대로 되돌린다.

허용 범위를 넷으로 못박는다.

1. **글로우** — 히어로와 대시보드 섹션 배경 2곳. 그 외에는 쓰지 않는다
2. **그림자** — 카드 부양·hover. 앱 화면은 `--shadow-0` 유지
3. **모션** — 카드 스택 순회, 3D 뒤집기, 스크롤 진입 1회. 전부 `prefers-reduced-motion` 존중
4. **`--brand-yellow` 의 세 번째 사용처** — 숫자 하이라이트. 지금 문서는 "만료 배너·결제 버튼 둘뿐"으로 못박혀 있다. 랜딩에는 만료 배너가 없어 의미 충돌은 없다

**앱 화면(`(app)/`)의 원칙은 그대로다.** 이 절은 `(marketing)` 라우트에만 적용된다.

## 컴포넌트 분해

`page.tsx` 가 지금 301줄이고, 섹션이 5개에서 7개로 늘면서 인터랙션 상태까지 들어온다. 한 파일에 두면 감당이 안 된다. **섹션을 컴포넌트로 가른다.**

| 파일 | 역할 | 상태 |
|---|---|---|
| `src/components/landing/InsightCardStack.tsx` | ① 카드 스택 · 토글 · 뒤집기 | 로컬 상태 3개(active / mode / flipped) |
| `src/components/landing/CsvToSignals.tsx` | ② CSV ↔ 지적 연결 | 로컬 상태 1개(focus) |
| `src/components/landing/SignalTypeGrid.tsx` | ③ 지적 5종 | 상태 없음 |
| `src/components/landing/DashboardShowcase.tsx` | ⑤ 대시보드 + 떠 있는 카드 | 상태 없음 |
| `src/components/landing/Highlight.tsx` | I3 하이라이트 + 툴팁 | 상태 없음 (hover·focus를 CSS로만 처리) |
| `src/components/LandingStepPreview.tsx` | ④ 3단계 미리보기 | 기존 파일, 3번째만 교체 |
| `src/app/(marketing)/page.tsx` | 조립 + OAuth | 기존 파일, 대폭 축소 |

`page.tsx` 는 `useSearchParams` 와 OAuth 때문에 `"use client"` 이고, 그 아래는 전부 클라이언트에서 렌더된다. 위 표의 "상태 없음"은 서버 컴포넌트라는 뜻이 아니라 **훅을 쓰지 않는다**는 뜻이다.

**예시 데이터는 `src/lib/landing-samples.ts` 한 곳에 둔다.** 카드 3장, CSV 9줄, 지적 3건, 근거 거래 행이 전부 여기서 온다. 임계값 문구는 이 파일이 `SIGNAL_THRESHOLDS` 를 읽어 만든다 — 임계값이 바뀌면 랜딩 문구도 따라 바뀌어야 하고, 그러지 않으면 랜딩이 거짓말을 하게 된다.

## 테스트

`src/app/(marketing)/page.test.tsx` 가 이미 있고 그중 **3건이 깨진다.** TDD로 간다 — 먼저 테스트를 고치고 새 테스트를 쓴 뒤 구현한다.

| 깨지는 테스트 | 이유 |
|---|---|
| `renders the finsight wordmark and a tool-sized value proposition heading` | h1 이 `CSV` 를 담는지 보는데, 새 제목에는 `CSV` 가 없다 |
| `labels the sample sentences as examples rather than real data` | 검사 대상인 `예시 문장` 리스트가 사라진다 |
| `lifts the amount out of each sample sentence so the number reads first` | 같은 리스트와 `sample-amount` testid 가 사라진다 |

앞 둘의 **의도는 살려서 새 구조로 옮긴다** — h1 은 제품이 무엇인지 담아야 하고, 예시 데이터에는 "예시" 표시가 붙어야 한다. 세 번째의 "금액이 문장보다 먼저 읽혀야 한다"는 의도는 인사이트 카드의 영향도 금액 검사로 옮긴다.

새로 덮을 것:

- 히어로에 인사이트 카드 3장이 있고 각각 신호 종류·영향도 금액·문장을 갖는다
- "예시" 표시가 히어로와 대시보드 미리보기에 있다
- 신뢰 문구("금액은 계산된 값입니다")가 히어로에 있다
- 토글을 누르면 원자료 뷰가 보이고 AI 문장 뷰가 숨는다 (그 반대도)
- 토글이 보이는 임계값 문자열이 `SIGNAL_THRESHOLDS` 에서 온 값과 일치한다
- `근거 보기` 를 누르면 근거 행이 접근 가능해진다
- CSV 줄에 focus 하면 대응 지적이 강조된다 (`data-focus` 속성)
- ③이 `SIGNAL_TYPES` 5종을 전부 렌더한다
- 정본 3단계 문구가 그대로다 (기존 테스트 유지)
- 3단계 3번째 미리보기가 "근거 패널"이다

`src/components/landing/*.test.tsx` 로 컴포넌트별 테스트도 함께 둔다.

- macOS "동작 줄이기"를 켠 상태에서 자동 순환과 진입 애니메이션이 멈추는지 확인
- 배포 전 `npx supabase db push --dry-run` — 이 작업에 마이그레이션은 없지만 프리플라이트 훅이 확인한다

## 참고
