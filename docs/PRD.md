# PRD: FinSight

## 목표
아무 형식의 CSV 거래내역이든 업로드하면 자동으로 분류해, 이번 달 돈이 어디로 갔는지 바로 보여준다.

## 사용자
가계부를 쓰고 싶지만 매번 손으로 입력하다 포기한 개인 소비자. 카드사·은행 사이트에서 거래내역 CSV를 내려받을 수 있고, 엑셀로 직접 집계하기는 귀찮은 사람.

## 핵심 기능
1. **CSV 업로드와 자동 컬럼 매핑** — 카드사마다 다른 CSV 형식을 LLM이 읽어 날짜·금액·가맹점 컬럼을 스스로 찾는다. 사용자는 어떤 형식인지 설명할 필요가 없다. 자동 매핑이 실패하면 컬럼을 직접 지정하는 화면으로 넘어간다
2. **자동 카테고리 분류와 지출 대시보드** — 거래를 10종 카테고리로 분류해 카테고리별 지출, 전월 대비 증감, 상위 가맹점을 보여준다. 분류가 틀리면 사용자가 고칠 수 있고, 고친 내용은 그 사용자에게 계속 적용된다
3. **AI 리뷰** — 평소와 다른 소비를 짚어준다. 어떤 소비가 특이한지는 결정론적 SQL이 5종 신호(카테고리 급증 / 큰 첫 가맹점 / 이상 거래 / 반복 결제 / 구독료 인상)로 탐지하고, 원화 영향도 순으로 정렬한다. LLM은 선별된 신호를 문장으로 옮기기만 한다. 세 곳에 나타난다 — 업로드 직후 인사이트 카드(상위 3개), 월간 리포트의 코칭 문단, 반복 지출 목록(LLM 미사용)
4. **LLM 서술형 월간 리포트** — 선택한 달의 소비 패턴을 문장으로 설명한다. 모든 수치는 DB 집계값이며 LLM은 그 숫자를 문장으로 엮기만 한다
5. **체험과 구독** — 가입하면 카드 등록 없이 7일 무료 체험. 체험이 끝나면 신규 업로드와 리포트 생성만 막히고, 이미 올린 데이터는 계속 볼 수 있다. 결제는 Polar

## MVP 제외 사항
- 자연어 질문 채팅 ("지난달 카페에 얼마 썼어?")
- 부정결제·도용 탐지 (AI 리뷰와 다른 기능이다. 리뷰는 "평소와 다른 소비"를 짚고, 부정결제 탐지는 "본인이 하지 않은 결제"를 찾는다. 후자는 CSV만으로 판정할 근거가 없다)
- 사용자 정의 카테고리 (카테고리는 고정 10종)
- 은행·카드사 계좌 직접 연동 (CSV 업로드만)
- 예산 설정과 목표 관리
- 분류 정확도 관리자 도구 (수정 이력은 로그로만 남긴다)

## 운영 정책
- **원본 CSV 보관**: 구독 중에는 무기한 보관. 구독 해지 시 30일 유예 후 원본 파일만 삭제하고 파싱된 거래 데이터는 유지한다. 계정 삭제 시 전체 즉시 삭제. 사용자는 업로드 목록에서 개별 파일을 언제든 삭제할 수 있다
- **로그인**: Google OAuth 단독
- **카테고리**: 식비 / 카페·간식 / 교통 / 주거·통신 / 쇼핑 / 의료·건강 / 문화·여가 / 교육 / 금융·보험 / 기타
- **환불·입금 처리**: 지출 집계에는 지출만 넣는다. 환불·취소·입금은 따로 표시하고 원래 지출에서 빼지 않는다. 3월에 30만원을 쓰고 15만원을 환불받으면 3월 지출은 30만원으로 남고 환불 15만원이 별도로 보인다
