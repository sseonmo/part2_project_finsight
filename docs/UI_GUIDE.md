# UI 디자인 가이드

## 디자인 원칙
1. **도구처럼 보여야 한다.** 마케팅 페이지가 아니라 매일 쓰는 대시보드다. 첫 화면에서 이번 달 지출·카테고리·최근 거래가 스크롤 없이 보이는 것이 랜딩용 히어로 섹션보다 중요하다.
2. **색은 의미가 있을 때만 쓴다.** 기본은 무채색이고, 색이 붙는 곳은 지출 증가·감소·경고·에러뿐이다. 장식으로 쓴 색이 하나 늘 때마다 진짜 신호가 그만큼 묻힌다.
3. **숫자가 주인공이다.** 금액과 증감률이 화면에서 가장 먼저 읽혀야 한다. 카드 테두리·아이콘·라벨은 숫자보다 약하게 둔다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |
| 카테고리 10종을 각각 다른 색으로 칠하기 | 무지개 차트는 읽히지 않는다. 순서와 길이로 구분한다 |

## 색상

라이트·다크 두 벌을 정의하고 `prefers-color-scheme` 을 따른다. 토큰 이름은 하나이고 값만 모드별로 바뀐다. 컴포넌트에 원시 색상값을 직접 쓰지 않는다.

토큰 이름은 아래 표가 단일 출처다. 컴포넌트는 이 이름만 참조하고 16진수 값을 직접 쓰지 않는다.

### 배경
| 용도 | 토큰 | 라이트 | 다크 |
|------|------|--------|------|
| 페이지 | `--bg` | #ffffff | #0a0a0a |
| 카드 | `--bg-card` | #fafafa | #141414 |
| 경계선 | `--border` | #e5e5e5 | #262626 |
| 강조 표면 (hover, 선택) | `--bg-muted` | #f5f5f5 | #1f1f1f |

### 텍스트
| 용도 | 토큰 | 라이트 | 다크 |
|------|------|--------|------|
| 주 텍스트 (금액, 제목) | `--text` | #0a0a0a | #fafafa |
| 본문 | `--text-body` | #404040 | #d4d4d4 |
| 보조 (라벨, 날짜) | `--text-muted` | #737373 | #a3a3a3 |
| 비활성 | `--text-disabled` | #a3a3a3 | #525252 |

### 데이터/시맨틱 색상
| 용도 | 토큰 | 라이트 | 다크 |
|------|------|--------|------|
| 지출 증가 · 경고 | `--up` | #dc2626 | #ef4444 |
| 지출 감소 · 성공 | `--down` | #16a34a | #22c55e |
| 변화 없음 · 중립 | `--flat` | #737373 | #a3a3a3 |
| 막대 그래프 | `--bar` | #404040 | #d4d4d4 |

**지출이 늘면 빨강, 줄면 초록이다.** 국내 증시 관례와 반대지만 가계부에서는 지출 증가가 주의해야 할 신호다. 이 규칙을 화면마다 뒤집지 않는다.

**증감을 색으로만 표현하지 않는다.** ▲ ▼ 기호와 부호를 함께 쓴다. 색만 쓰면 적록색약 사용자에게 아무 정보가 없다.

## 컴포넌트

### 카드
```
rounded-lg border border-[var(--border)] bg-[var(--bg-card)] p-4
```
그림자를 쓰지 않는다. 경계선만으로 구분한다. 강조가 필요한 카드는 그림자 대신 경계선 색을 한 단계 진하게 한다.

### 버튼
```
Primary:   rounded-md bg-[var(--text)] text-[var(--bg)] px-4 py-2 text-sm font-medium
Secondary: rounded-md border border-[var(--border)] px-4 py-2 text-sm
Text:      text-sm text-[var(--text-muted)] hover:text-[var(--text-body)]
Danger:    rounded-md border border-[var(--up)] text-[var(--up)] px-4 py-2 text-sm
```
파괴적 동작(계정 삭제, 파일 삭제)만 Danger를 쓴다. 그 외에 빨강을 쓰지 않는다.

### 입력 필드
```
rounded-md border border-[var(--border)] bg-[var(--bg)] px-3 py-2 text-sm
focus: 경계선 색을 --text-body 로. 링(ring) 글로우를 쓰지 않는다
```

### 데이터 표시
- **금액은 `tabular-nums` 로 렌더하고 우측 정렬한다.** 자릿수가 흔들리면 표가 읽히지 않는다
- 천 단위 구분 쉼표 + `원` 접미. 소수점은 표시하지 않는다
- 카테고리 막대는 단색이고 길이로만 크기를 표현한다. 카테고리별 색상 코딩을 하지 않는다
- 빈 상태는 일러스트 없이 한 문장과 다음 행동 버튼으로만 구성한다

## 레이아웃
- 전체 너비: `max-w-6xl` (대시보드는 표가 넓다). 랜딩만 `max-w-4xl`
- 정렬: 좌측 정렬 기본. 숫자 열만 우측 정렬. 중앙 정렬은 빈 상태와 로딩에만
- 간격: 요소 간 `gap-3`, 섹션 간 `space-y-6`. 카드 내부 `p-4`
- 대시보드는 세로 한 줄로 쌓는다. 2단 그리드는 화면이 `lg` 이상일 때만

## 타이포그래피

폰트는 시스템 스택을 쓴다. 웹폰트를 불러오지 않는다 — 첫 로딩이 느려지고 한글 웹폰트는 용량이 크다.

| 용도 | 스타일 |
|------|--------|
| 페이지 제목 | text-2xl font-semibold text-[var(--text)] |
| 큰 금액 (이번 달 합계) | text-3xl font-semibold tabular-nums text-[var(--text)] |
| 섹션 제목 | text-sm font-medium text-[var(--text-muted)] |
| 표 본문 · 금액 | text-sm tabular-nums text-[var(--text-body)] |
| 보조 정보 (날짜, 건수) | text-xs text-[var(--text-muted)] |
| LLM 서술 문단 | text-sm text-[var(--text-body)] leading-relaxed |

## 애니메이션
- fade-in (150ms) — 카드·리스트가 처음 나타날 때
- 진행률 바 width 트랜지션 (300ms) — 업로드 처리 중
- 그 외 모든 애니메이션 금지. 특히 hover 확대, 스크롤 연동 등장, 숫자 카운트업을 쓰지 않는다

숫자 카운트업은 특히 쓰지 않는다. 금액이 흘러가는 동안 사용자는 그 값을 읽을 수 없고, 가계부에서 숫자는 볼거리가 아니라 정보다.

## 아이콘
- SVG 인라인, `strokeWidth 1.5`, 크기 16px 기본
- 아이콘 컨테이너(둥근 배경 박스)로 감싸지 않는다
- 텍스트로 충분한 자리에 아이콘을 넣지 않는다. 카테고리에 이모지·아이콘을 붙이지 않는다
