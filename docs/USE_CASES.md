# 유즈케이스

`docs/USER_FLOW.md` 의 시나리오 42건을 발췌하고, 각 건에 **액터**와 **화면**을 덧붙인 문서다.

> **출처는 `USER_FLOW.md` 다.** 시나리오 번호(S*)·흐름·문구가 어긋나면 `USER_FLOW.md` 가 맞다.
> 새 시나리오는 `USER_FLOW.md` 에 먼저 추가하고 여기로 옮긴다.
> 상태 머신·권한 매트릭스·마찰점·프로토타입 누락분은 옮기지 않았다 — 원본을 볼 것.
> 각 절 머리에 원본의 어느 표에서 왔는지 `출처` 로 적어 두었다. 원본 표 3개(정상 흐름 / 분기·예외 / AI 리뷰)를 주제별 6개 절로 재배치했으므로 절 구성은 원본과 1:1이 아니다.
> 줄 번호가 아니라 섹션 이름으로 가리킨다 — 원본이 길어져도 어긋나지 않게.
>
> 각 유즈케이스를 **브라우저에서 실행하는 절차**는 `docs/BROWSER_TEST_CASES.md` 에 있다.
